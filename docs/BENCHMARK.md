### 方法论
- **梯度检验**：中心差分 `(L(θ+ε)−L(θ−ε))/2ε`，判据 `|ana−num| ≤ 1e-7 + 1e-4·max(|ana|,|num|)`，每项抽 ≤60 参数（GQA 500）。
- **RoPE 不变性**：整体平移后任意两位置注意力分数差异应恰为 0（旋转的正交性）。
- **量化保真**：对称逐张量 INT8（weight-only PTQ），误差纯为舍入，理论有界、解码无损。
- **KV 加速比**：生成 N token 时增量(forwardStep)总耗时 vs 每次全量重算(forward)总耗时之比（5 次取最优）。
